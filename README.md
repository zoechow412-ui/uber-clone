# 安心代駕 Expo App（開發測試版）

以 [Ryde Uber Clone](https://github.com/sanidhyy/uber-clone) 的 React Native / Expo 專案為基礎，保留原生手機 App 的導航與叫車產品方向，加入香港「司機駕駛客人自己的車」測試流程。原項目 MIT 授權及版權保留。

## 用 Expo Go 在手機測試

需要 Node.js 及 pnpm。在專案目錄執行：

```sh
pnpm install --ignore-scripts
pnpm exec expo start --go
```

用 iPhone 相機或 Android Expo Go 掃描終端機顯示的 QR code。手機和開發電腦需連接同一個 Wi-Fi。測試 App 不需要 Clerk、Google Maps、Neon 或 Stripe 金鑰。

## 手機內測試流程

1. 「叫代駕」填寫上車點、目的地、即時／預約時間、客人車牌和車況，並確認保險及車主授權。
2. 「我的」批准測試司機。
3. 「司機」上線並接取待處理預約，到場後核對車牌、車況及保險。
4. 三項現場核對完成後才可開始行程；完成行程前還要確認交還車匙及客人確認。
5. 「行程」查看狀態和紀錄。

所有角色共用同一個手機上的本機測試資料，使用 Expo SecureStore 儲存。這是單機原型，未連接伺服器，其他手機看不到同一筆訂單。

## 測試版限制

司機批准、接單和訂單管理只在本機模擬。未接入真實帳戶及管理員權限、即時派單、定位／導航、保險公司核保、付款、收據、推送通知或跨裝置同步。地圖區目前是手機內的路線示意，未連接地圖服務。請勿輸入真實身份、車牌或保單資料。實際營運前須完成司機資格、私隱、法律及保險保障核實。

原版需要服務金鑰的登入及叫車服務保留在原始碼；本開發模式直接進入 Expo 手機測試 App，不要求新增付費服務。
