# 安心代駕（開發測試版）

以 [Ryde Uber Clone](https://github.com/sanidhyy/uber-clone) 的 Expo / React Native 專案及原有介面為基礎，加入香港代客駕駛客人自有車輛的本機流程。原項目版權及 MIT 授權保留，見 `LICENSE`。

## 免費本機測試

需要 Node.js 及 pnpm。安裝依賴後執行：

```sh
pnpm install --ignore-scripts
pnpm exec expo start
```

用 Expo Go 掃描終端機顯示的 QR code 開啟手機版。測試畫面會直接開啟「安心代駕」開發版，無須 Clerk、Google Maps、Neon 或 Stripe 金鑰。此 Expo 51 專案以手機版為測試目標。

## 建議測試流程

1. 在乘客頁填寫接車點、目的地、客人車牌、車款、車況、測試保單編號及有效日期，並確認保險聲明和車主授權，建立測試訂單。
2. 切換「管理」批准測試司機。
3. 切換「司機」上線並接單，到達接車點。
4. 打開「行程及現場核對」，完成車牌、車況、保險核對，才可開始代駕。
5. 標記交還車匙及客人確認，然後完成行程。資料可以在「我的行程」及管理角色查看。

資料儲存在目前裝置的本機儲存區；手機使用 Expo SecureStore，Web 使用瀏覽器 localStorage。其他裝置不會收到更新。

## 測試版範圍

這是可操作的介面及訂單流程原型。司機審批只是一個本機示範開關。未連接真實帳戶或管理員權限、跨裝置資料庫、即時派單、即時定位、導航、保險公司核保、付款、收據或推送通知。保單參考欄只作虛構測試輸入，請勿輸入真實身份、車輛或保單資料。開始實際營運前，須先取得保險公司對收費代駕服務的書面承保確認，並完成法律、私隱和司機資格核實。

正式版設定 `EXPO_PUBLIC_DEMO_MODE=false` 後會進入原 Ryde 登入及叫車程式；該路徑仍需要原項目的 Clerk、Neon、Google Maps 及 Stripe 設定。
